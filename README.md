# AI 음식 레시피 챗봇

## 1. 프로젝트 소개

본 프로젝트는 오픈소스 인공지능 모델을 활용하여 음식 사진을 분석하고, 해당 음식에 대한 한국어 레시피를 제공하는 생성형 AI 기반 웹앱입니다.

사용자는 음식 사진과 요청 문장을 입력할 수 있으며, 시스템은 음식명을 추정하고 초보자도 따라할 수 있는 레시피를 대화형으로 제공합니다.

---

## 2. 사용 기술

- Python
- Gradio
- PyTorch
- Hugging Face Transformers
- BLIP
- CLIP

---

## 3. 사용한 오픈소스 모델

### BLIP
- 모델명: Salesforce/blip-image-captioning-base
- 역할: 음식 이미지에 대한 캡션 생성

### CLIP
- 모델명: openai/clip-vit-base-patch32
- 역할: 이미지와 음식 후보 텍스트 간 유사도 비교

---

## 4. 주요 기능

1. 음식 사진 업로드
2. 이미지 기반 음식명 추정
3. 한국어 레시피 생성
4. 추가 요청 반영
   - 더 맵게 만들기
   - 다이어트 버전
   - 초보자용 설명
   - 1인분 기준 설명
5. 대화형 UI 제공

---

## 5. 실행 방법

### 1단계: 설치

처음 실행하는 경우 `install.bat` 파일을 더블클릭합니다.

필요한 Python 라이브러리가 자동으로 설치됩니다.

### 2단계: 실행

설치가 끝난 뒤 `run.bat` 파일을 더블클릭합니다.

브라우저에서 Gradio 웹앱이 실행됩니다.

---

## 6. 주의사항

첫 실행 시 BLIP, CLIP 모델이 자동으로 다운로드되므로 시간이 걸릴 수 있습니다.

모델 파일 용량이 크기 때문에 인터넷 연결이 필요합니다.

---

## 7. 한계 및 개선 방향

현재 버전은 BLIP과 CLIP을 활용하여 음식 후보를 추정하는 프로토타입입니다.

비슷한 형태의 음식은 잘못 분류될 수 있습니다.

향후에는 Food-101 기반 음식 분류 모델 또는 대형 오픈소스 LLM을 추가 연결하여 음식 인식 정확도와 레시피 품질을 개선할 수 있습니다.
