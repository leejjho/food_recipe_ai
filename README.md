# AI 음식 레시피 챗봇

## 1. 프로젝트 개요

본 프로젝트는 음식 이미지를 입력하면 AI가 음식명을 추정하고, 사용자가 따라할 수 있는 한국어 레시피를 제공하는 생성형 AI 기반 음식 레시피 챗봇입니다.

사용자는 음식 사진과 요청 문장을 함께 입력할 수 있으며, 시스템은 이미지 분석 결과를 바탕으로 음식 후보를 추정하고 대화형 UI를 통해 레시피를 제공합니다.

본 프로젝트는 오픈소스 인공지능 모델인 BLIP, CLIP을 활용하여 이미지 이해 기능을 구현하였고, GPT-2 기반 생성형 AI 실험 구조를 함께 고려하여 생성형 AI 시스템 형태로 구성하였습니다.

---

## 2. 프로젝트 주제

### 주제명

**오픈소스 생성형 AI 기반 음식 이미지 레시피 생성 시스템**

### 핵심 아이디어

음식 사진을 입력하면 AI가 다음 과정을 수행합니다.

1. 음식 이미지 분석
2. 음식명 추정
3. 한국어 레시피 생성
4. 사용자 추가 요청 반영
5. 대화형 인터페이스로 결과 제공

---

## 3. 개발 목적

일상에서 음식 사진을 보았을 때 음식명이나 조리 방법을 바로 알기 어려운 경우가 있습니다.

본 프로젝트는 이미지 이해 모델과 생성형 AI 기술을 결합하여, 사용자가 음식 사진만으로도 해당 음식에 대한 조리 정보를 얻을 수 있도록 하는 것을 목표로 합니다.

특히 초보자도 쉽게 따라할 수 있도록 조리 절차를 단계별로 제공하는 데 초점을 두었습니다.

|---|---|

## 5. 사용한 오픈소스 모델

### 5.1 BLIP

- 모델명: `Salesforce/blip-image-captioning-base`
- 역할: 입력된 음식 이미지에 대한 텍스트 캡션 생성
- 예시: 음식 사진 → "a bowl of stew", "a plate of tacos" 등

### 5.2 CLIP

- 모델명: `openai/clip-vit-base-patch32`
- 역할: 음식 이미지와 음식 후보 텍스트 간 유사도 비교
- 방식: 여러 음식 후보 중 이미지와 가장 유사한 음식을 선택

### 5.3 GPT-2 관련 실험 방향

- 모델명: `gpt2`
- 역할: 생성형 LLM 기반 레시피 생성 실험
- 한계: 기본 GPT-2는 영어 중심 모델이기 때문에 한국어 레시피 생성 품질에는 한계가 있음
- 개선 방향: 향후 한국어 또는 다국어 지시형 오픈소스 LLM으로 확장 가능

## 6. 시스템 구조

```text
음식 사진 입력
        ↓
BLIP 모델
이미지 캡션 생성
        ↓
CLIP 모델
음식 후보와 이미지 유사도 비교
        ↓
Top-1 음식명 자동 선택
        ↓
한국어 레시피 생성
        ↓
Gradio 대화형 UI 출력
